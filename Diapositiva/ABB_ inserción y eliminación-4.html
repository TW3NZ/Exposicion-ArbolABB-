ABBinserción y eliminación

1¿Qué es un árbol?

Concepto

Un árbol es una estructura de datos jerárquica y no lineal: un conjunto de nodos conectados por aristas, con un nodo inicial y sin ciclos.

Interacción

Elige un concepto o haz clic en un nodo del árbol.

Aplicación

Un sistema de archivos es un árbol: las carpetas contienen otras carpetas y archivos, de forma jerárquica.

Visualización

2¿Qué es un nodo?

Concepto

Un nodo es la unidad básica del árbol. Guarda un dato y referencias a otros nodos. En un árbol binario son dos: izquierda y derecha. Si no hay hijo, la referencia es nula (nullptr).

struct Nodo {
  int   dato;
  Nodo* izq;  // hijo izquierdo
  Nodo* der;  // hijo derecho
};
Aplicación

En memoria, cada nodo es un objeto independiente. Las referencias (punteros) permiten pasar de un nodo a otro; sin ellas, los nodos quedarían aislados.

Visualización
Interacción

Selecciona un nodo y sigue sus referencias.

3¿Qué es la raíz?

Concepto

La raíz es el nodo más alto del árbol y el único que no tiene padre. Es el punto de entrada: desde ella se llega a todos los demás nodos. En código se guarda como un puntero, Nodo* raiz; si el árbol está vacío, vale nullptr.

Interacción

Aplicación

Toda operación sobre el árbol (buscar, insertar, eliminar) empieza en la raíz.

Visualización

4¿Qué es un ABB?

Concepto

Un árbol binario de búsqueda es un árbol binario donde cada nodo N cumple una propiedad de orden:

Subárbol izquierdo
valores < N
N
Subárbol derecho
valores > N

En esta presentación se asume que no hay valores repetidos.

Interacción

Escribe un valor y observa cómo la propiedad de orden decide el camino.
